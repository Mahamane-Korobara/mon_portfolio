# Portfolio — Mahamane Korobara

Site portfolio personnel (version React/Vite) présentant profil, compétences et projets, avec animations et gestion du SEO côté client.

## Fonctionnalités

- Page d'accueil unique (`pages/Home.jsx`) structurée en sections.
- Composants réutilisables (`components/ui`, `components/portfolio`) et données centralisées (`components/data`).
- Gestion des métadonnées SEO (`components/SEO.jsx`).
- Navigation via React Router, animations Framer Motion.

## Stack

React 19 · Vite · React Router · Tailwind CSS · Framer Motion

## Démarrage

```bash
npm install
npm run dev
```
